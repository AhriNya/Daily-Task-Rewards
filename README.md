**🌌 Bing 自动搜索**

一款高颜值、全自动的 Bing 搜索助手。拥有极具现代感的“液态玻璃”界面和流畅的动画效果，在后台默默帮你完成每日搜索任务。

**✨ 核心功能**

🎨绝美视觉体验
  采用通透的“液态玻璃”悬浮面板。打字时伴有流光溢彩的“全息波浪”动画，长休息时有专属的“呼吸流光”特效，彻底告别枯燥死板的传统脚本界面。

🤖全自动搜索流程
  自动抓取全网实时热搜，结合智能词库生成搜索词。自动模拟输入、自动跳转搜索、自动滚动阅读搜索结果，全程无需手动干预。

🛡️拟真安全机制
  深度模拟真人的打字节奏、鼠标滑动轨迹和页面浏览习惯。内置“工作-休息”作息规律，每完成几轮搜索会自动进入“深度休眠”，有效降低账号被限制或弹出验证码的风险。

⚡丝滑流畅交互
  所有的倒计时、进度条和面板动画均经过深度优化，如系统原生动画般丝滑流畅，拒绝卡顿、掉帧和数字跳变。

🎛️极简控制面板
  提供一键启动、强制跳过等待、查看搜索历史等快捷操作，当前运行状态和剩余时间一目了然。

**🚀 使用方法**

1. 安装脚本后，打开 Bing 首页。
2. 点击页面左下角的**图标**即可一键启动。
3. 任务运行中，可通过悬浮面板随时查看进度、跳过冷却或停止脚本。

**⚠️ 温馨提示**

本脚本仅供日常辅助与学习交流使用。为了保证账号安全，**建议保持默认的运行节奏**，切勿过度修改代码参数进行高频刷量，以免触发搜索引擎的人机验证。
